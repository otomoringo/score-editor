鳴らすパート 出力

音符を入れる

ASDF JKL;ド レ ミ ファ ソ ラ シ ド（白鍵）
WE UIOド♯ レ♯ ファ♯ ソ♯ ラ♯（黒鍵）
左Shift+鍵1オクターブ下
右Shift+鍵1オクターブ上
R / 0休符
Insert上書き⇔挿入の切り替え。上書き（ふだんはこちら）は、入れた長さぶん後ろを上書きし、ほかの小節は動かない。挿入は手前に差し込み、後ろがずれる
ZXCVB次に入れる長さ: 全音符・2分・4分・8分・16分（数字の 1〜5 でも同じ）
Alt+長さカーソルの音符の長さを変える（伸ばすと後ろを上書き、縮めると休符が残る）
.付点の切り替え
Tタイ（同じ高さの音を後ろにつなぐ）

直す

↑ ↓半音上げる・下げる
Ctrl+↑ ↓1オクターブ上げる・下げる
Deleteカーソルの音符を休符に戻す
Backspaceカーソルの手前を休符に戻す
Ctrl+Z / Y元に戻す・やり直す

範囲選択とコピー

マウスで囲む囲んだ音符を選択（複数の段もまとめて選べる）
Shift+← →カーソルの段で選択を伸ばす
Ctrl+C / Xコピー／切り取り
Ctrl+Vカーソル位置に貼り付け（その長さぶん上書き）
Delete選択した音符を休符に戻す
Esc選択を解除

移動

← →前後の音符へ
Ctrl+← →前後の小節へ
Home / Endパートの先頭・末尾へ
PageUp / PageDown上・下のパートへ（Alt+↑↓ でも可）
クリックその音符へ移動。まだ書いていない先の小節をクリックすると、そこから書き始められる

歌詞

Enterカーソルの音符の歌詞を入力
Space / Tab確定して次の音符へ
Shift+Tab確定して前の音符へ
Enter / Esc確定して歌詞入力を終える

聴く

Spaceカーソル位置から再生・停止
Shift+Space先頭から再生
Hカーソル位置の4声の和音を鳴らす
マウスを乗せるその拍の4声が鳴る

色の意味

■ 赤カーソル（選択中の音符）
■ 青パートの末尾（ここに追加される）
